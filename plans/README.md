## The finding behind half of this list

Four of poof's measurement systems were broken at the same time, and **every one
of them reported healthy**:

| instrument | actual state | what it reported |
|---|---|---|
| wide funnel | `ENOENT` on every production fire for 13 days | cron heartbeat `dispatched=true` |
| funnel outcome scorer | calls a Finnhub endpoint that 403s on the free tier | nothing, silently |
| evals workflow | `Trading 212 API error 401`, 10 consecutive failures | red in a tab nobody opens |
| SPY benchmark | reported +397.56pp of alpha that did not exist | a spectacular quarter |

Individual bugs are cheaper than this pattern. Plan 001 exists so the next dead
instrument announces itself.

## Dependency notes

- **001 blocks everything.** The installed `node_modules` does not match the
  lockfile (`ai` 7.0.0-beta.178 vs 7.0.28, `typescript` 7.0.1-rc vs 7.0.2) and
  local Node was 22 against `engines: 24.x`. Until that is fixed, a green
  `pnpm test` is a statement about a dependency tree nobody deploys. Every
  other plan's verification gate depends on this being true first.
- **005 bundles three defects** (intent written after the send, a mid-batch
  throw discarding filled orders, and the exit path passing no intent guard at
  all) because they edit the same loop body in `agent/lib/orders.ts`. Splitting
  them would manufacture a merge conflict and two reviews of the same code.
  They are three separate commits inside one branch.
- **010 depends on 009** because 009 establishes the CI conventions 010 extends.
- **016 depends on 015.** Re-deriving exit constants without the replay harness
  is guessing with extra steps: every sweep run so far measured a six-month
  buy-and-hold signal, not poof's ~10-20 day catalyst entries.
- **015 depends on 002.** Replaying trades through a trailing stop that cannot
  fire would bake the bug into the baseline you compare against.

## Findings considered and rejected

- **Split `convex/memory.ts` (1378 lines).** Not worth doing. Fan-in is 1 (the
  `agent/lib/memory.ts` facade), the pure decision logic is already extracted
  into `convex/memoryPolicy.ts` and `convex/traceAppend.ts` and both are tested,
  and a split renames every `api.memory.*` call site for no behavioural gain.
- **Add a linter/formatter.** Not worth doing now. There are zero `any`,
  `@ts-ignore` or floating-promise instances in non-test source, and neither
  no-floating-promises candidate was real. No rule set would have caught any bug
  in this audit. Revisit if a second person starts committing.
- **Upgrade `eve` 0.22.1 → 0.68.x.** Deferred, not rejected. The `^0.22.1` caret
  on a 0.x range is why it never moves, which is worth knowing, but 0.68 requires
  `ai ^7.0.105` (a hard peer) and Node >= 24, so it is a coupled three-package
  migration. Do it when something is actually wanted from it, not on principle.
- **Make `trades.status` a `v.union` of literals.** Deferred. Real debt (four
  vocabularies, three incompatible "is closed" predicates, one bug already
  caused) but it is a schema change against a populated table on the money path,
  and money-path *bugs* are open. Revisit after 001-008 land.
- **Build the Alpaca intraday experiment.** Parked by the user on 2026-09-30, and
  independently flagged by the direction audit as the thing not to do: paper
  money cannot compound a real £250 account, and an intraday loop needs either
  many jittered cron files or leaving the Vercel Hobby plan.
